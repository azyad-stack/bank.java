# 🏦 Bank Desktop Application

An academic project where I built a banking desktop application using **Java** and the **MVC architecture**, separating business logic from the user interface.

This project helped me understand software design structure, clean code organization, and database integration in real-world scenarios.

---

## ✨ Technologies Used

- Java
- JavaFX
- FXML
- CSS
- SQLite
- MVC Architecture

---

## 🚀 Features

### 🔐 Admin Interface
- Add new clients
- Delete clients
- Deposit money into client accounts
- Update client passwords

### 👤 Client Interface
- Transfer money between saving and checking accounts
- Transfer money to other clients using their username
- Secure login system

---

## 📍 What I Learned

- Implementing MVC architecture properly
- Separating business logic from UI
- Handling database operations with SQLite
- Managing authentication and user roles
- Designing clean and maintainable JavaFX interfaces
